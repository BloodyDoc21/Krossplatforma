# Лабораторная работа №1 — Консольный калькулятор

Консольное приложение-калькулятор на Qt с использованием механизма сигналов и слотов, метаобъектной системы Qt и профилирования времени выполнения операций.

## Индивидуальное задание

**Продвинутый уровень, вариант 14 — калькулятор с профилированием.**

Требуется использовать `QElapsedTimer` для измерения времени выполнения операций и выводить полученное время в консоль.

## Цель работы

Изучение механизма сигналов и слотов Qt на примере консольного приложения, наследования от `QObject`, создания собственных сигналов и слотов, установки соединений через `QObject::connect()` и работы с метаобъектной системой Qt.

## Возможности

Программа поддерживает следующие команды:

| Команда | Описание |
|---|---|
| `add a b` | Сложение двух чисел |
| `sub a b` | Вычитание двух чисел |
| `mul a b` | Умножение двух чисел |
| `div a b` | Деление двух чисел |
| `reset` | Сброс результата |
| `help` | Вывод справки |
| `quit` | Завершение программы |

После выполнения арифметической операции программа выводит:

- результат вычисления;
- время выполнения операции в миллисекундах.

При делении на ноль и некорректном вводе выводится сообщение об ошибке.

## Архитектура

Основная логика реализована в классе `Calculator`, который наследуется от `QObject`.

Для работы механизма сигналов и слотов используется макрос `Q_OBJECT`.

### Сигналы

- `resultReady(double)` — сообщает о готовом результате;
- `errorOccurred(const QString&)` — сообщает об ошибке;
- `operationTimed(double)` — передаёт время выполнения операции.

### Слоты

- `add(double, double)`
- `subtract(double, double)`
- `multiply(double, double)`
- `divide(double, double)`
- `reset()`

Соединение сигналов и обработчиков выполняется через современный синтаксис `QObject::connect()` с указателями на методы.

## Профилирование

Для измерения времени выполнения каждой операции используется `QElapsedTimer`.

Измерение выполняется непосредственно внутри соответствующего слота:

1. создаётся `QElapsedTimer`;
2. запускается таймер;
3. выполняется операция;
4. измеряется прошедшее время;
5. излучается сигнал `operationTimed`.

Время выводится в миллисекундах.
